# Claude Project Reference

This directory contains local Claude Code reference instructions for the University Cafeteria Pre-Order App.

## Files

- `../CLAUDE.md` — main project instructions.
- `requirements.md` — assignment requirements and scope.
- `architecture.md` — system architecture.
- `frontend.md` — frontend responsibilities and UX.
- `backend.md` — backend responsibilities and business rules.
- `database.md` — data model guidance.
- `api.md` — API conventions.
- `security.md` — security and authorization.
- `testing.md` — testing strategy.
- `ui-ux.md` — interface and usability.
- `coding-conventions.md` — coding standards.
- `dev-workflow.md` — development workflow.
- `risk-management.md` — assignment risks and controls.
- `deployment.md` — deployment guidance.
- `academic-submission.md` — academic traceability and submission guidance.
- `feature-checklist.md` — implementation checklist.

## Usage

Keep these files local if they are intended only as Claude Code context.

Do not treat these files as application source code.

If a requirement changes, update `requirements.md` and the relevant reference file before implementing the change.
